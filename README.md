# ToDoList01

![Status](https://img.shields.io/badge/status-learning%20project-6e7781?style=flat-square)
![SwiftUI](https://img.shields.io/badge/SwiftUI-0A84FF?style=flat-square&logo=swift&logoColor=white)

The starting point for a SwiftUI to-do list app: a fresh Xcode project from a Swift lab session, ready for the to-do features to be added.

## Run it

```sh
open ToDoList.xcodeproj
```

Choose an iPhone simulator and press Run.

```
ToDoList/
├── ToDoListApp.swift   App entry point
└── ContentView.swift   Main view
```

For a working list app with saved data, see [GetSet](https://github.com/manav-Mnv/GetSet).
